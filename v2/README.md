# Журнал работы водителя v2.0

## 📋 Краткое описание

Модернизированная версия приложения для учета доходов и расходов водителей курьерских служб с улучшенной архитектурой и новыми возможностями.

## 🔧 Что изменено в v2.0

### Архитектурные улучшения

1. **Единая модульная структура**
   - Удалено дублирование кода между старыми и новыми модулями
   - Все модули теперь находятся в `src/`
   - Централизованное управление состоянием через Store

2. **Конфигурация и константы**
   - Вынесены все магические числа в `src/config/constants.js`
   - Firebase конфигурация импортируется из констант
   - Легко настраиваемые параметры приложения

3. **Улучшенная обработка ошибок**
   - Retry-логика для Firebase операций
   - Offline-режим с очередью операций
   - Явные сообщения об ошибках

4. **Новые утилиты**
   - `asyncUtils.js` - debounce, throttle, retry
   - Проверка онлайн-статуса
   - Обёртка для безопасной обработки промисов

### Технические улучшения

- ✅ Vite сборщик для быстрой разработки
- ✅ Vitest для тестирования
- ✅ ESLint + Prettier для качества кода
- ✅ JSDoc документация для всех API
- ✅ Custom events для реактивности между модулями
